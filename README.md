# Contact App

A modern and responsive frontend web application built with **React** and **Vite**, focusing on clean UI, reusable components, and an intuitive user experience.

## 🌐 Live Demo

- **Live Site:** https://contactapp-rumman.vercel.app/

## 📂 Repository

- **GitHub:** https://github.com/irfanrumman/assignment5

---

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices.
- Built with reusable React components.
- Client-side routing using React Router.
- Modern and clean user interface.
- Fast development and optimized production build with Vite.
- Organized and maintainable project structure.

## 🛠️ Technologies Used

- React Router

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/irfanrumman/assignment5.git
```

Go to the project directory:

```bash
cd assignment5
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
